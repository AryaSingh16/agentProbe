# Screenshots Guide

Place the captured application screenshots in this directory with the following filenames:

- `overview.png`: The Reliability Matrix and aggregate KPIs overview.
- `run-lab.png`: The single run and full matrix evaluation lab with agent policy selection.
- `trace.png`: Deep execution trace with tool-call citations and automated diagnosis.
- `insights.png`: What-if risk estimator and export workbench.

### How to Capture:
1. Start the stack: `docker compose up --build`
2. Open `http://localhost:3000` in your browser.
3. Navigate to each tab (**Overview**, **Run Lab**, **Trace & Diagnosis**, and **Insights & Export**) and capture screenshots using your OS snipping tool (e.g. `Win + Shift + S` or `Cmd + Shift + 4`).
4. Save the images into this folder using the filenames listed above.
